# Cab Hustle

A portrait arcade taxi game built with Flutter and Flame.

## Game Overview

Cab Hustle is a casual taxi arcade game featuring:
- **Single-button control**: Tap and hold to accelerate, release to stop
- **Automatic pathfinding**: Vehicle navigates automatically to destinations
- **Timing-based gameplay**: Success depends on when to move, not how to steer
- **Daily Shift**: one shared course per day, with a ghost of your best attempt to race
- **Endless Shift**: three-strike runs with a bank-or-push decision at every dropoff
- **Near-miss economy**: precision driving scores, not distance
- **Vehicle collection**: unlock vehicles with real handling differences

## Features

- 🎮 Simple, accessible gameplay (one-handed control)
- 🚗 Multiple unlockable vehicles with distinct handling
- 🎨 Original top-down sprite art
- 🎵 Sound effects and music (CC0 or generated in-repo)
- 📱 iPhone-only, portrait
- 💾 On-device progress, no account or network
- 🏆 Records, lifetime stats, and achievements

## Technical Stack

- **Framework**: Flutter 3.x
- **Game Engine**: Flame 1.11+
- **Language**: Dart
- **State Management**: Provider
- **Storage**: SharedPreferences

## Getting Started

### Prerequisites

- Flutter SDK 3.0 or higher
- Dart SDK 3.0 or higher

### Installation

1. Clone the repository
```bash
git clone https://github.com/wjdavis5/taxiGame.git
cd taxiGame/taxi_game
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the game
```bash
flutter run
```

### Building for Production

```bash
# iOS (the shipping platform)
flutter build ios --release

# Android (on demand; the CI job exists, but the platform does not ship)
flutter build apk --release
```

- **Tap and Hold**: Accelerate forward
- **Release**: Stop immediately
- **Pause Button**: Pause the game

## Assets and licenses

Every bundled asset's source and license is recorded in
`assets/licenses/LICENSES.txt`: vehicle sprites and UI icons are Kenney CC0
work (some recoloured or elongated in-repo by `tool/make_vehicle_sprites.py`),
the engine loop, brake squeal, and music loop are synthesized in-repo by
`tool/make_generated_audio.dart`, and the app icon and launch images are
generated by `tools/make_app_icon.swift`. Nothing bundled requires
attribution; the Credits screen carries the courtesy credit.
