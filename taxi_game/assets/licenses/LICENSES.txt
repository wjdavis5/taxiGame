## Removed assets

The following were removed from the bundle because `AudioService` is a stub —
no audio is played anywhere in the app, so these shipped as dead weight while
carrying live license obligations.

  assets/audio/music/menu_music.mp3   — Kevin MacLeod / Incompetech, CC-BY 4.0.
                                        Required attribution; 8.7 MB.
  assets/audio/sfx/ui/button_click.wav   — provenance never established.
  assets/audio/sfx/ui/coin_collect.wav   — provenance never established.
  assets/audio/sfx/ui/level_complete.wav — provenance never established.

The `flame_audio` dependency was removed alongside them; nothing imported it.

If audio is reintroduced, each file must be re-listed above with a confirmed
source and license before it ships, and any attribution-required asset must be
credited in the app's Credits screen. A CC-BY asset obligates attribution on
distribution, not merely on playback — bundling one without credit is a license
violation even if it never plays.

## Maintaining this file

When an asset is added to the bundle:
1. Add it under its source heading with the exact filename.
2. Record source URL, artist, and license.
3. If the license requires attribution, add the credit to the Credits screen.
4. Never ship an asset whose provenance cannot be established.
