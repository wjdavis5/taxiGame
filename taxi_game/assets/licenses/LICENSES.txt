# Asset Licenses for Cab Hustle

Every file shipped in this app's bundle is listed below with its source and
license. Audio ships again as of issue #4; every audio file carries a
confirmed source, and nothing attribution-required is bundled.

---

## Audio Assets

### Sound effects and jingles (Kenney.nl, CC0)

Source packs (all by Kenney Vleugels, all CC0 1.0 Universal — attribution not
required; a courtesy credit is shown in the app's Credits screen):
  Impact Sounds  — https://kenney.nl/assets/impact-sounds
  Digital Audio  — https://kenney.nl/assets/digital-audio
  UI Audio       — https://kenney.nl/assets/ui-audio
  Music Jingles  — https://kenney.nl/assets/music-jingles

The packs ship OGG Vorbis, which no Apple platform decodes (audioplayers'
Darwin backend plays through AVFoundation), so each file was converted to
16-bit PCM WAV — a pure format conversion of the same CC0 audio, no content
change. Shipped files, `assets/audio/sfx/` (original pack file → shipped as):

  Impact Sounds/impactMetal_heavy_000.ogg  → crash.wav    (traffic crash)
  Impact Sounds/impactMetal_light_001.ogg  → scrape.wav   (low-speed scrape)
  Digital Audio/pepSound1.ogg              → pickup.wav   (passenger boards)
  Digital Audio/twoTone1.ogg               → dropoff.wav  (fare delivered)
  Digital Audio/threeTone1.ogg             → coin.wav     (coin award)
  UI Audio/switch2.ogg                     → ui_click.wav (menu/button press)

Moment jingles — `assets/audio/music/`:
  Music Jingles/Pizzicato jingles/jingles_PIZZI02.ogg → jingle_banked.wav
  Music Jingles/8-Bit jingles/jingles_NES05.ogg       → jingle_complete.wav
  Music Jingles/Hit jingles/jingles_HIT03.ogg         → jingle_wrecked.wav

### Generated audio (self-made in-repo, no third-party rights)

Three files are synthesized by `tool/make_generated_audio.dart` — procedural
generation, no sampled third-party audio — so they carry no license
obligation at all. Regenerate with `dart run tool/make_generated_audio.dart`
from `taxi_game/`; the RNG is seeded and the output is byte-stable.

  assets/audio/sfx/engine_loop.wav    — engine hum loop (volume tracks speed)
  assets/audio/sfx/brake.wav          — tyre squeal on a deliberate brake
  assets/audio/music/shift_loop.wav   — the music track, loops under play

## Maintaining this file

When an asset is added to the bundle:
1. Add it under its source heading with the exact filename.
2. Record source URL, artist, and license.
3. If the license requires attribution, add the credit to the Credits screen.
4. Never ship an asset whose provenance cannot be established.
